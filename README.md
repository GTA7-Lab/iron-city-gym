# Academia Iron City — GTA7 Lab

Grade de aulas coletivas com filtros e servidor MCP (`search_classes`, `get_class`).

```bash
npm install
npm run dev            # http://localhost:3000
npm run test:mcp       # testa http://localhost:3000/mcp
```

Deploy: importar o repositório na Vercel (framework Next.js, sem configuração extra).
O endpoint MCP fica em `https://<projeto>.vercel.app/mcp`.
